מדיניות פרטיות — Spawnync

עודכן: 12 באוקטובר 2026

מה האפליקציה שומרת

Spawnync שומרת רק את קובצי השמירה של המשחקים שהמשתמש בחר לסנכרן, ופרטים טכניים עליהם (מספר גרסה, שם המכשיר שממנו עלו, שעה וזמן משחק). הכל נשמר ב-Google Drive של המשתמש עצמו, בתיקייה בשם Spawnync, ובמחשב של המשתמש (גיבויים מקומיים).

הגישה ל-Google Drive

האפליקציה מבקשת רק את ההרשאה drive.file: היא רואה ומשנה רק קבצים שהיא עצמה יצרה, ואינה יכולה לראות שום קובץ אחר בדרייב. כתובת האימייל של החשבון מוצגת רק בתוך האפליקציה, כדי שהמשתמש ידע לאיזה חשבון התחבר.

תמונות ושמות של משחקים

כדי להציג את התמונה האמיתית של כל משחק, האפליקציה מחפשת את המשחק בחנות Steam לפי השם שלו בלבד (למשל "Silver Pines"), ומורידה את התמונות שלו משרתי התמונות של Steam. לחנות נשלח רק שם המשחק — בלי חשבון, בלי מפתח, ובלי שום פרט על המשתמש או על המחשב. התמונות נשמרות במחשב של המשתמש, והמספר של המשחק בחנות נשמר עם המשחק בתיקייה Spawnync בדרייב, כדי שהמכשיר השני יציג את אותה תמונה. משחק שלא נמצא בחנות מוצג עם הסמל שבקובץ המשחק עצמו, שנקרא מהמחשב ולא נשלח לשום מקום.

מה לא קורה

  • שום מידע לא נשלח לשרת שלנו — אין לנו שרת. מלבד Google Drive של המשתמש, האפליקציה פונה רק לחנות Steam (שם המשחק, כדי למצוא את התמונה שלו) ול-GitHub (כדי לבדוק אם יש גרסה חדשה של האפליקציה).
  • אין אנליטיקה, אין מעקב, אין פרסומות, ושום מידע לא נמכר או משותף.
  • השימוש במידע שמתקבל מ-Google עומד ב-Google API Services User Data Policy, כולל דרישות Limited Use.

מחיקה

אפשר לנתק את Google Drive מתוך האפליקציה, לבטל את ההרשאה בכתובת myaccount.google.com/permissions, ולמחוק את התיקייה Spawnync מהדרייב. הסרת האפליקציה מהמחשב מוחקת אותה; הגיבויים המקומיים נמצאים בתיקיית הנתונים של האפליקציה.

Privacy policy — Spawnync

Updated: October 12, 2026

What the app stores

Spawnync stores only the save files of the games the user chose to sync, plus technical details about them (a revision number, the name of the device that uploaded them, time and play time). Everything is stored in the user's own Google Drive, in a folder named Spawnync, and on the user's own computer (local backups).

Google Drive access

The app requests only the drive.file scope: it can see and change only files it created itself, and cannot see any other file in the user's Drive. The account's email address is shown only inside the app, so the user knows which account is connected.

Game pictures and names

To show each game's real artwork, the app looks the game up in the Steam store by its name only (for example "Silver Pines") and downloads its pictures from Steam's image servers. Only the game's name is sent to the store — no account, no key, and nothing about the user or the computer. The pictures are kept on the user's computer, and the game's Steam store number is kept with the game in the Spawnync folder in Drive, so the other device shows the same picture. A game that is not in the store is shown with the icon inside its own game file, which is read on the computer and sent nowhere.

What does not happen

  • No data is sent to servers of ours — there are none. Besides the user's own Google Drive, the app contacts only the Steam store (a game's name, to find its picture) and GitHub (to check whether a newer version of the app exists).
  • No analytics, no tracking, no ads; no data is sold or shared.
  • Spawnync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

You can disconnect Google Drive inside the app, revoke access at myaccount.google.com/permissions, and delete the Spawnync folder from your Drive. Uninstalling the app removes it from the computer; local backups live in the app's data folder.
